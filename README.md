# Newline TV

White-label IPTV-приложение для оператора **NEWLINE network**.

## Что внутри

- Заставка с логотипом оператора и предзагрузкой списка каналов.
- Два источника: **IPTVPORTAL** (домен оператора) и **M3U-плейлист оператора**.
  Адрес плейлиста зашит в приложение и не показывается в интерфейсе.
- Плеер на **libVLC 3.7.2** — декодирует кодеки оператора, включая MPEG-2,
  MPEG-4, H.264/HEVC, HLS (m3u8) и HTTP/HTTPS-потоки.
- Бесконечное автовосстановление потока: при обрыве приложение переподключается
  с нарастающей паузой, пока эфир не вернётся. Звук и видео синхронизированы.
- Автостарт при запуске: последний просмотренный канал, а если его нет — первый.
- Сетка каналов с навигацией по пульту (D-pad), логотипами и EPG «Сейчас/Далее».
- Телепрограмма для **M3U** берётся из внешнего XMLTV-сервиса IPTVX
  (`https://iptvx.one/EPG_LITE`): каналы сопоставляются по названию, программа
  кэшируется на 12 часов. Для IPTVPORTAL используется EPG портала, а если его
  нет — тот же внешний источник.
- Два вида списка каналов: **плитки** и **компактный список**; в каждой строке
  показывается текущая передача (мини-EPG) для каналов с телепрограммой.
- Полупрозрачный список каналов поверх играющего видео (Back или Menu на пульте,
  свайп слева направо на сенсорном экране): выбор переключает канал, Back скрывает,
  следующий Back — выход. Прозрачность списка и плиток настраивается.
- Управление в плеере с пульта: вверх/вниз — переключение каналов,
  ОК — телепрограмма канала, влево/вправо — тоже переключение,
  Back и Menu — список каналов.
- Сенсорное управление в плеере: тап — информация о канале и что идёт
  (5 секунд), свайп слева направо — список каналов, свайп справа
  налево — телепрограмма (EPG).
- Настройки: тёмная тема, выбор источника, масштаб шрифта 50–150 % с живым примером,
  отдельный шрифт телепрограммы 50–150 %, вид списка каналов, включение/отключение
  списка поверх видео и его прозрачность.
- Телепрограмма открывается в отдельном окне: текущая передача подсвечена,
  список сразу прокручен к ней, а если данные ещё загружаются — окно остаётся
  открытым и заполняется на месте.
- **Автообновление с GitHub**: при запуске приложение проверяет последний релиз
  (не чаще раза в 6 часов), предлагает установить новую версию, скачивает APK
  с прогрессом и запускает системный установщик. Перед установкой проверяются
  имя пакета и подпись APK. Ручная проверка — в настройках.
- Поддержка телефонов и Android TV: `LEANBACK_LAUNCHER`, баннер, управление пультом.

## Сборка

```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot"
cd D:\Android\NewlineTV
.\gradlew.bat assembleRelease
```

Готовый APK: `app\build\outputs\apk\release\app-release.apk`

Release-подпись настраивается через локальный `keystore.properties`
(в репозиторий не попадает):

```properties
storeFile=D:/Android/keys/newline-release.jks
storePassword=...
keyAlias=newline
keyPassword=...
```

Сам ключ лежит вне проекта: `D:\Android\keys\newline-release.jks`.
Сохраните резервную копию ключа и паролей — без них невозможно выпустить
обновление, которое установится поверх текущей версии.

Версию можно переопределить для тестовой сборки:

```powershell
.\gradlew.bat assembleRelease -PappVersionCode=1 -PappVersionName=1.0.0
```

## Установка

Готовые APK публикуются на странице релизов:

<https://github.com/jeysson89/newline-tv/releases/latest>

```powershell
adb install -r NewlineTV-1.1.1.apk
```

На ТВ — через USB-накопитель или `adb connect <ip-tv>:5555`.

Приложение подписано release-ключом. Первая установка поверх старой
debug-сборки потребует удалить её (настройки при этом сбросятся).
Все последующие версии устанавливаются обновлением без удаления.

## Автообновление

- Приложение запрашивает `https://github.com/jeysson89/newline-tv/releases/latest`
  и определяет версию по редиректу на тег релиза. Это не расходует лимит
  GitHub API (60 запросов в час на IP), что важно для абонентов за NAT.
  Если редирект недоступен, используется GitHub API как резервный вариант.
- APK скачивается по фиксированному имени: **`NewlineTV-<версия>.apk`**
  (например, `NewlineTV-1.1.1.apk`). Это имя обязательно должно совпадать
  с версией в теге релиза.
- Скачанный файл проверяется: package name `com.newline.tv` и подпись должны
  совпадать с установленным приложением.
- Если установка из неизвестных источников запрещена, приложение открывает
  нужный экран настроек и после возврата продолжает установку автоматически.
- На части устройств Google Play Защита проверяет APK при установке. Если
  появилось предупреждение, выберите «Проверить» и дождитесь окончания проверки.
  Если проверка вернула «Вредоносное приложение заблокировано», установите APK
  вручную с компьютера (`adb install -r NewlineTV-<версия>.apk`) или временно
  отключите сканирование в Google Play → Play Защита → шестерёнка.

### Как выпустить новую версию

1. Поднимите `versionCode` и `versionName` в `app/build.gradle`.
2. Соберите `assembleRelease`.
3. Скопируйте APK в `NewlineTV-<version>.apk`.
4. Создайте релиз с тегом `v<version>` и приложите APK:

```powershell
gh release create v1.2.0 .\NewlineTV-1.2.0.apk `
  --repo jeysson89/newline-tv `
  --title "Newline TV 1.2.0" `
  --notes "Что нового: ..."
```

## Структура

```
app/src/main/java/com/newline/tv/
  SplashActivity.java          — заставка и предзагрузка каналов
  MainActivity.java            — сетка каналов
  PlayerActivity.java          — плеер, OSD, EPG, автовосстановление, оверлей
  SettingsActivity.java        — настройки и ручная проверка обновлений
  BaseActivity.java            — тема, шрифт, возврат из установщика
  FontScale.java               — применение масштаба шрифта
  NewlineApp.java              — инициализация приложения
  data/Channel.java            — модель канала
  data/EpgProgram.java         — модель передачи EPG
  data/M3uParser.java          — разбор M3U
  data/PlaylistRepository.java — загрузка списка и кэш
  data/PortalClient.java       — клиент IPTVPORTAL
  data/Settings.java           — настройки, источник, последний канал
  data/XmltvEpg.java           — внешний EPG для M3U и кэш телепрограммы
  ui/ChannelAdapter.java       — адаптер плиток, компактного списка и оверлея
  ui/ImageLoader.java          — загрузка логотипов
  ui/MaxWidthLinearLayout.java — ограничение ширины контента
  update/UpdateManager.java    — проверка релизов, загрузка и установка APK
```

## Примечания

- Плейлист оператора зашит в код и не редактируется из интерфейса.
- IPTVPORTAL использует домен оператора; данные терминала подставляются автоматически.
- Демо-каналы и встроенные тестовые ролики в сборку не входят.
- Репозиторий публичный: адрес плейлиста и контакты поддержки видны в исходниках.
