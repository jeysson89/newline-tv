# Newline TV — обновления

Здесь публикуются только готовые APK. Исходный код приложения закрыт.

Этот репозиторий оставлен по прежнему адресу, чтобы версии 1.3.11 и старше
смогли получить обновление 1.3.12. Начиная с 1.3.12 приложение проверяет
релизы в репозитории [newline-tv-releases](https://github.com/jeysson89/newline-tv-releases/releases/latest).

- Последняя версия: **1.3.12** (`NewlineTV-1.3.12.apk`)
- Установка: `adb install -r NewlineTV-1.3.12.apk`
- После 1.3.12 обновления приходят автоматически.
